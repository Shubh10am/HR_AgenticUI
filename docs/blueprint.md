# **App Name**: HR Streamline AI

## Core Features:

- AI-Powered Email Assistance: AI fetches email data and generates draft responses, streamlining email handling. It will function as a tool for creating responses. HR admins review and approve before sending.
- Attendance & Reporting: Displays an individual monthly attendance report. Includes details of productivity and behavior.
- Unified Communication: Integrates with Email, Slack, Google Meet, Zoom, and Microsoft Teams to aggregate communications data, logging interactions for HR insights.
- AI Recruitment System: Using an AI tool, generate JDs using prompts. Resume Filtering: Screens and shortlists candidates. Manage applications. Send automated tasks/tests. AI Interviewer conducts technical and HR interview rounds, analyzing candidate fit and availability.
- Smart Email Drafting: Allows HR to draft email using an AI-assisted prompting tool to write professional emails, ready for review and dispatch.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey professionalism and trust.
- Background color: Light gray (#ECEFF1) for a clean, modern feel. This subtle background will allow the information-rich UI to stand out, with minimal distraction.
- Accent color: A vibrant purple (#7E57C2) to highlight important actions and calls to action. This is close to the primary in hue, providing both interest and cohesion.
- Clean and modern typography to ensure readability and convey professionalism.
- Consistent and clear icons to aid navigation and comprehension.
- A structured and intuitive layout to present complex HR data in an easily digestible format.
